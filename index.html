ESP32 RFID Controller

USB firmware installation for RFID-controlled linear actuators.

Install in four steps

  1. Use a Windows, macOS or Linux computer with Google Chrome or Microsoft Edge.
  2. Disconnect the actuator motor power before updating. Connect the ESP32 to the computer using a data-capable USB cable.
  3. Click Install Firmware, select the ESP32 serial port and follow the instructions.
  4. Wait until installation is complete. Disconnect and reconnect the ESP32, then test according to the device manual.
Important: Disconnect the actuator power supply before installing firmware. Keep the ESP32 connected via USB until installation is complete.

Firmware installation

This browser does not support serial installation. Use the latest desktop Chrome or Edge. Open this installer from an HTTPS website.

This installer must be hosted over HTTPS, for example using GitHub Pages. Do not open the HTML file directly from your computer. USB drivers may be required. Installing firmware may overwrite existing device settings.
